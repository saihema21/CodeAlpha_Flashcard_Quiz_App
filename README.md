# 🧠 Flashcard Quiz App

A professional and interactive **Flashcard Quiz App** developed as part of the **CodeAlpha App Development Internship**.

The application helps users learn and revise concepts through interactive flashcards, providing a simple and engaging study experience with question-and-answer functionality.

---

## 🚀 Features

* 📚 **Interactive Flashcards** — View questions and reveal answers.
* 👁️ **Show Answer** — Display the answer for the current question.
* ⬅️ **Previous / Next Navigation** — Move easily between flashcards.
* ➕ **Add Flashcards** — Create your own study questions and answers.
* ✏️ **Edit Flashcards** — Update existing flashcard content.
* 🗑️ **Delete Flashcards** — Remove unwanted flashcards.
* 📊 **Study Progress** — Track the current position and learning progress.
* 🎨 **Professional UI** — Clean, modern, and responsive interface.
* 💻 **Web-Based Application** — Built using Streamlit for easy access and deployment.

---

## 🛠️ Technologies Used

* **Python**
* **Streamlit**
* **HTML/CSS**
* **Session State** for managing flashcard data

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/CodeAlpha_Flashcard_Quiz_App.git
```

### 2. Navigate to the Project Folder

```bash
cd CodeAlpha_Flashcard_Quiz_App
```

### 3. Create a Virtual Environment

```bash
python -m venv .venv
```

### 4. Activate the Virtual Environment

**Windows PowerShell:**

```powershell
.\.venv\Scripts\Activate.ps1
```

### 5. Install Dependencies

```bash
python -m pip install -r requirements.txt
```

### 6. Run the Application

```bash
streamlit run app.py
```

The application will open in your browser.

---

## 🎯 How It Works

1. Open the Flashcard Quiz App.
2. Read the question displayed on the flashcard.
3. Click **Show Answer** to reveal the answer.
4. Use **Next** and **Previous** to navigate between cards.
5. Add new flashcards using the **Add Flashcard** option.
6. Edit or delete existing flashcards from the management section.
7. Use the progress information to track your study session.
